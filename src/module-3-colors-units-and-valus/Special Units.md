## 3. 🛠️ Special Units (Function-based)

| Function  | Description                                                 | Example                              | Usage                                   |
| --------- | ----------------------------------------------------------- | ------------------------------------ | --------------------------------------- |
| `calc()`  | Perform mathematical calculations using different units     | `width: calc(100% - 60px);`          | Responsive layouts                      |
| `clamp()` | Set a value between a minimum, preferred, and maximum value | `font-size: clamp(1rem, 2vw, 2rem);` | Responsive typography                   |
| `min()`   | Uses the **smallest** value from the given values           | `width: min(100%, 600px);`           | Prevent elements from becoming too wide |
| `max()`   | Uses the **largest** value from the given values            | `padding: max(20px, 5vw);`           | Maintain a minimum size or spacing      |
