
### 1. 📦 Absolute Units

| Unit | Name       | Description                       | Example            |
| ---- | ---------- | --------------------------------- | ------------------ |
| `px` | Pixel      | 1 device pixel (common base unit) | `font-size: 16px;` |
| `pt` | Point      | 1/72 of 1 inch (used in print)    | `font-size: 12pt;` |
| `cm` | Centimeter | Rare, print-oriented              | `width: 5cm;`      |
| `mm` | Millimeter | Rare, print-oriented              | `height: 10mm;`    |
| `in` | Inch       | 1in = 96px = 2.54cm               | `width: 1in;`      |
| `pc` | Pica       | 1pc = 12pt                        | `font-size: 1pc;`  |


| Unit | Looks Like                | Common Usage                     |
| ---- | ------------------------- | -------------------------------- |
| `px` | 📱 Fixed screen pixels    | Websites, apps, UI (most common) |
| `pt` | 🖨️ Print font size       | Documents, PDFs                  |
| `cm` | 📏 Physical centimeters   | Printed pages                    |
| `mm` | 📐 Physical millimeters   | Business cards, labels           |
| `in` | 📄 Physical inches        | Print layouts                    |
| `pc` | 📝 Typography measurement | Professional print design        |
